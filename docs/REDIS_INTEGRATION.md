# 🚀 Redis Integration for Echo MCP

This document explains the comprehensive Redis integration implemented in the Echo MCP platform for **faster data retrieval**, **enhanced performance**, and **scalability**.\n\n## 🎯 Overview\n\nRedis has been integrated into Echo MCP to provide:\n\n- **⚡ Lightning-fast data retrieval** with in-memory caching\n- **🔄 Session management** with automatic expiration\n- **💬 Real-time chat performance** with message caching\n- **🍕 External API response caching** for food and ride services\n- **📊 Analytics caching** for frequently accessed statistics\n- **🌐 Scalability** for high-concurrent user scenarios\n\n---\n\n## 🏗️ Architecture\n\n### Core Components\n\n1. **Redis Manager** (`app/core/redis.py`)\n   - Connection pool management\n   - Automatic failover handling\n   - Health monitoring\n\n2. **Cache Service** (`app/core/redis.py`)\n   - High-level caching operations\n   - Serialization/deserialization\n   - TTL management\n   - Pattern-based deletion\n\n3. **Enhanced Services**\n   - `RedisChatService` - Chat with caching\n   - `RedisAuthService` - Authentication with session caching\n   - `RedisFoodService` - Food service with API caching\n\n---\n\n## 🔧 Configuration\n\n### Environment Variables\n\n```bash\n# Redis Connection\nREDIS_URL=redis://localhost:6379/0\nREDIS_HOST=localhost\nREDIS_PORT=6379\nREDIS_DB=0\nREDIS_PASSWORD=your_redis_password\nREDIS_ENABLED=true\n\n# Cache TTL Settings (seconds)\nCACHE_TTL_SECONDS=3600          # Default cache TTL\nCHAT_CACHE_TTL_SECONDS=300      # Chat data TTL (5 minutes)\nSESSION_CACHE_TTL_SECONDS=1800  # Session TTL (30 minutes)\nUSER_CACHE_TTL_SECONDS=600      # User data TTL (10 minutes)\n```\n\n### Redis Setup\n\n#### Local Development\n```bash\n# Install Redis (macOS)\nbrew install redis\nbrew services start redis\n\n# Install Redis (Ubuntu)\nsudo apt update\nsudo apt install redis-server\nsudo systemctl start redis-server\n\n# Verify Redis is running\nredis-cli ping\n# Should return: PONG\n```\n\n#### Docker Setup\n```yaml\n# docker-compose.yml\nversion: '3.8'\nservices:\n  redis:\n    image: redis:7-alpine\n    ports:\n      - \"6379:6379\"\n    volumes:\n      - redis_data:/data\n    command: redis-server --appendonly yes\n    \nvolumes:\n  redis_data:\n```\n\n#### Production Configuration\n```bash\n# Example production Redis URL with authentication\nREDIS_URL=redis://:password@redis-cluster.example.com:6379/0\nREDIS_PASSWORD=your_strong_redis_password\n```\n\n---\n\n## 📚 Caching Strategies\n\n### 1. **Chat Service Caching**\n\n#### **Message Caching**\n```python\n# Cache keys\nchat:messages:{room_id}:page:{page}        # Paginated messages\nchat:recent_messages:{room_id}:limit:{n}   # Recent messages (1min TTL)\nchat:room:{room_id}                        # Room metadata\n```\n\n#### **Direct Messages**\n```python\n# Cache keys\nchat:direct:{user1_id}:{user2_id}:page:{page}  # Direct message history\nchat:conversations:{user_id}                    # User conversations list\n```\n\n#### **Real-time Features**\n```python\n# Active users tracking\nchat:active_users:{room_id}     # Users currently in room\nusers:online                    # Global online users\n```\n\n### 2. **Authentication Caching**\n\n#### **Session Management**\n```python\n# Cache keys\nsession:{token}                 # Session data with auto-expiration\nuser:{user_id}                  # User profile data\nuser:email:{email}              # Email-to-user mapping\nuser:sessions:count:{user_id}   # Active session count\n```\n\n### 3. **Food Service Caching**\n\n#### **External API Responses**\n```python\n# Cache keys\nfood:restaurants:{search_hash}              # Restaurant search results (30min)\nfood:restaurant_details:{restaurant_id}    # Restaurant details (1hr)\nfood:restaurant_menu:{restaurant_id}       # Menu items (2hr)\n```\n\n#### **User Data**\n```python\n# Cache keys\nfood:user_orders:{user_id}:skip:{skip}:limit:{limit}  # User order history\nfood:user_stats:{user_id}                             # User order statistics\n```\n\n#### **Analytics**\n```python\n# Cache keys\nfood:popular_restaurants:limit:{limit}     # Popular restaurants (4hr)\nfood:trending_cuisines                     # Trending cuisines (6hr)\n```\n\n---\n\n## ⚡ Performance Benefits\n\n### Operations\n\n```python\nfrom app.core.redis import cache_service\n\n# Set cache with TTL\nawait cache_service.set(\"user:123\", user_data, ttl=600)\n\n# Get from cache\nuser_data = await cache_service.get(\"user:123\")\n\n# Delete cache\nawait cache_service.delete(\"user:123\")\n\n# Pattern deletion\nawait cache_service.delete_pattern(\"user:*\")\n```\n\n### Chat Service with Invalidation Strategies\n\n### 1. **Time-based Expiration (TTL)**\n- Automatic cache expiration\n- Different TTLs for different data types\n- Prevents stale data\n\n### 2. **Event-based Invalidation**\n- Invalidate cache when data changes\n- Pattern-based deletion\n- Selective invalidation\n\n### 3. **Write-through Caching**\n- Update cache when data is modified\n- Ensures consistency\n- Used for critical data\n\n### Example Cache Invalidation\n\n```python\n# When user updates profile\nasync def update_user_profile(user_id: int, profile_data: dict):\n    # Update database\n    updated_user = update_user_in_db(user_id, profile_data)\n    \n    # Invalidate user cache\n    await cache_service.delete(f\"user:{user_id}\")\n    await cache_service.delete_pattern(f\"user:email:*\")\n    \n    # Update cache with new data\n    await cache_service.set(f\"user:{user_id}\", updated_user.model_dump(), 600)\n    \n    return updated_user\n```\n\n---\n\n## 🏃‍♂️ Getting Started\n\n### 1. **Install Dependencies**\n```bash\nuv pip install redis aioredis pickle-mixin\n```\n\n### 2. **Start Redis**\n```bash\n# Local
